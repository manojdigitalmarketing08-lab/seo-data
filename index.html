Why an MCP Server, Not Just Another API

APIs solve half the problem. You still need someone — or some code — to call them, parse the response, and hand the result to whatever tool actually needs it. A Model Context Protocol server removes that middle step entirely: it describes its own capabilities to any connected AI client, so Claude, ChatGPT, or Cursor can discover the keyword and PageSpeed tools on their own and call them directly, with no custom glue code per client.

That matters most once AI agent tools become part of a real workflow rather than a one-off chat. An agent researching content ideas, auditing a client site, or drafting a brief doesn't need a developer to wire up a new endpoint every time it needs fresh data — it just asks the MCP server, the same way it would ask any other tool it already knows how to use.

get_keyword_ideas — find keyword ideas from a seed term

Input

  • country — string, target location

Returns

  • Average monthly searches

get_historical_keyword_metrics — monthly search volume over time

Input

  • keywords — array of strings
  • country — string, target location

Returns

  • Monthly search volume history

Input

Returns

  • Performance score
  • LCP, INP, CLS

Frequently Asked Questions

What is MCP?
Model Context Protocol is the open standard that lets AI assistants call outside tools and data sources the same way every time. Claude, ChatGPT, and Cursor can all talk directly to a server built on it, no custom integration required.
Which AI clients are supported?
ChatGPT, Claude Desktop, Claude Code, Cursor, and any other AI tools for SEO built to speak the same open protocol. Exact setup steps vary slightly by client, but the underlying connection works the same way everywhere.
Which keyword tools and data providers are supported?
Today, keyword data comes from Google Ads Keyword Planner, and page performance data comes from Google PageSpeed Insights. Both are queried live through the same server. Additional data providers are on the roadmap for later this year.
Do I need an API key?
Yes. Sign up free to get one — no credit card required for the Free tier. Your key authenticates every request you send through the MCP server, and every call counts against your monthly quota automatically.
Can I use it with Claude?
Yes — add the server to Claude's MCP configuration with your API key, and you can connect Claude to data directly, calling keyword and PageSpeed tools mid-conversation instead of switching to a separate dashboard.
Can I use it with ChatGPT?
Yes, anywhere ChatGPT supports external MCP connectors. Once configured, you can connect ChatGPT to data the same way you would with Claude or Cursor — same API key, same three tools, same quota.
Is my keyword data stored?
Lookups are cached by seed term and location to speed up repeat queries, and that cache isn't tied to your account. We only track usage against your monthly request quota, nothing more granular than that.
Can I build my own MCP tools?
Not yet. Today you get three built-in tools — Keyword Ideas, Historical Keyword Metrics, and PageSpeed Insights — through the same MCP server for AI clients. Custom tool support is on the roadmap.
